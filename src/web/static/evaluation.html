This page checks the system against itself. Thirty-four made-up patients, each with a known correct answer written by hand, are pushed through the real triage rules — the same code a live patient goes through. Press the button and you see how many it got right.

Watch the first number. Under-triage means a patient was graded less urgent than they should have been — sent home when they should have stayed. That is the only mistake here that can hurt someone, and it must be zero.

Over-triage costs a doctor a few minutes. Escalations are the system doing its job — handing a case to a person — not failures.

These are not your patients. Nothing here is a real case. To see why a real patient was graded the way they were, use Case reasoning.

The main run uses no AI at all — it is pure rules, so it finishes instantly and costs nothing. The second button also runs scripted patients through the live chat, which takes a few minutes and uses your API quota.
