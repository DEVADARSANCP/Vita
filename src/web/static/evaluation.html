VITA carries its own exam paper. These scenarios run through the real code — the same rule engine, the same intake loop — so this page is a result, not a claim.

The number that matters is under-triage, and it must be zero. Over-triage costs a clinician a few minutes; under-triage sends home a patient who should have stayed, and in the record it looks exactly like a case that was genuinely low risk. Escalations are correct behaviour, not failures.

The deterministic tier uses no model and finishes in milliseconds. The conversation tier calls Gemini once per turn, so on a free-tier key it is slow and consumes quota — which is why it is opt-in.
